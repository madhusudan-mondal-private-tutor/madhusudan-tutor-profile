# Madhusudan Mondal — Tutor Profile

This is a simple, mobile-friendly static website.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `madhusudan-tutor-profile`.
2. Upload `index.html` to the repository root and commit the file.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your site URL will appear in the Pages settings, usually:
   `https://YOUR-USERNAME.github.io/madhusudan-tutor-profile/`

Once it is live, share the published URL so the poster can include a working “Know More About Me” link and QR code.
